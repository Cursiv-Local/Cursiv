# Cursiv v3.14-U107 — dependable research profiles

The five existing research helpers now share scoped evidence, code checks and bounded model work.
[Validation and limits](U107-VALIDATION.md) records the measured implementation;
[release verification](U107-RELEASE-VERIFICATION.md) will record tagged packages and publication.

- `agents ask` reaches the intended workflow. It selects relevant shipped/personal profiles, respects
  explicit names and explains how to split requests above three roles. Personal overrides remain supported.
- Individual and group runs use one evidence snapshot with only each role's permitted view. Notebook
  checks and supported statistics use current matching records after corrections, with units, omissions
  and coverage stated. Full narrative requests exceeding the excerpt budget ask for a narrower scope.
- Drafts and synthesis are checked against supplied citations, record identifiers, quantities, units,
  computed statistics and action records. Unsupported claims are withdrawn; missing evidence stops the
  run before inference. Retrieved instructions cannot grant powers or serve as factual quantities.
- Single-role work skips synthesis. Native checks, simple statistics and routine recording guidance need
  no model. Actual model attempts share request, context and time limits across retries and review.
- Deferred tasks have real local read-only execution, durable claims, explicit outcomes and retained
  history. Empty or placeholder text cannot mark work complete. Legacy/interrupted work needs deliberate
  retry or reconciliation. Nothing replays automatically on restart.
- Cancellation and conversation/person/workspace changes reject stale replies and history. Desktop
  controls recover after workspace authorization changes. No new autonomous framework or tool authority.

Before the release version bump, Windows checks passed **2,382 tests, 15 skips and 19 subtests**, with
**45/45** in the separate automated USB gate. The installed Qwen3:4b-instruct comparison measured
**81.13% fewer group model tokens and 83.41% lower median completion time** on three comparable routine
tasks. Individual median time improved **14.21%**. These are small synthetic samples on one GPU;
ordinary-chat speed did not improve. Original/previously seen held-out profile retests met requested
substance **18/18 and 15/15**; these are Codex grading, not independent human accuracy scores.

General writing can still add unrequested timing rhetoric. Passing bounded source/action checks does
not prove every sentence true. Cache-hit and peak-memory measurements are unavailable. Physical-drive,
first-time-user and independent-review results are not claimed. Historical science/model scores and
experimental Field Station source are unchanged. Optional Hermes/Codex integrations retain their own
dependencies; the Fleet Dashboard remains a device view.

Final tagged CI, Windows/Mac packages, frozen self-tests, owner signatures and public-download checks
must pass before publication; preparation is not proof they completed. Owner authentication is separate
from Windows Authenticode and Apple notarization, which are not provided by this release.
