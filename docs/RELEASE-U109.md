# Cursiv v3.14-U109 — reliable installed-source inspection

U109 improves how Cursiv finds its own implementation and distinguishes checked
source from a model's interpretation. Development starts from published U108. [Release verification](U109-RELEASE-VERIFICATION.md)
records the completed tagged packages and public downloads; website deployment is
established separately by its publication receipt.

- Natural implementation questions reach bounded installed-source inspection
  before notebook, saved-memory and research-workspace actions. Those ordinary
  actions retain their existing routes and permission checks.
- Source evidence contains hash-checked declarations, excerpts, line ranges,
  source snapshot, conditional calls, registered callbacks and read coverage.
  Startup comes from the inspected build entry list and `__main__` guard.
- Imports inside conditional setup, lazy desktop backend bindings and the
  explicit chat facade can be traced across files. Static wiring remains
  distinct from observed execution and dynamic configuration.
- Ten feature areas have implementation discovery. Source, workspace, imported
  documents, external Field Copy data and runtime state remain separate scopes.
- Startup, bounded regex checks, local timeout/retry rules and Field Copy's
  reviewed copy rules have app-owned explanations tied to current witnesses.
  Memory storage, notebook integrity/corrections, BM25 document scoring and
  response-check limits also use reviewed rules where model prose misread code.
  Changed witnesses fail closed. Read-only audit hypotheses include a source
  location, trigger, reproduction approach, possible fix and regression plan.
- Missing matches, inaccessible files and stale source produce explicit
  uncertainty; selected evidence cannot prove a feature is absent. A Unicode
  separator inside a string no longer shifts Python source citations.

No source uploads, cloud fallback, automatic code execution or edits, additional
agents, dependencies, workspace permissions or Field Station changes are added.
The final isolated Windows source suite passed **2,584 tests, 15 skips and19 subtests**;
128 focused checks passed. Actual installed Qwen was used where model synthesis
was required; critical native explanations are identified separately in the receipts.
The dedicated USB45-test and native workspace63-test gates passed.
General model explanations can still omit branches or misinterpret semantics;
valid citations do not prove complete understanding or a confirmed defect.

are in [U109-HANDOFF](U109-HANDOFF.md). The owner authorized commit, push and release on October28,2026; publication status is recorded in the handoff.
