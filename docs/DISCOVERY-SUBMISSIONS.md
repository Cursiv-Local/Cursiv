## Independent review brief

Ask a reviewer to evaluate the app, not to promise a positive result or include predetermined praise.
Suggested reproducible tasks: install a verified package; ask a question from a supplied local document;
find a missing answer without inventing a source; record and correct a synthetic observation; verify
the notebook against an earlier trusted export; repeat a local task with the network disconnected;
and test a prepared Windows drive on a compatible second computer.

Supply public release notes, notebook integrity docs, hardware requirements and known limits. Ask for
the actual app/model/version, machine, observed results and failures. Do not create fake reviews,
undisclosed endorsements or mass outreach. The owner chooses recipients and approves any message.
