# Cursiv v3.14-U91 — natural workspace files and balanced philosophical replies

- Create, append, search and read workspace files using everyday language.
  Follow-ups can use a confirmed recent file or a unique partial filename.
- Keep quoted contents exact, show short native receipts and explain missing
  information plainly. Existing-file approval and workspace protections remain.
- Answer common contested philosophical questions with concise, balanced built-in
  overviews. Broader discussions receive shared instructions to acknowledge
  disagreement and distinguish evidence from normative premises.
- Preserve explicitly requested arguments as labeled perspectives. Definitions,
  factual questions, safety guidance and notebook operations retain their paths.
- Make Help test Cursiv easier to find with a wide blue link above the website
  navigation, while keeping the primary download buttons.
- Require Windows/Mac workspace tests, full source suites and security checks on
  protected main before the supported release helper creates a tag.

## Evidence and limits

The full isolated Windows suite passed **1,749 tests / 1 platform skip** with the locked release dependencies. Hosted Mac checks passed **1,735 / 15 skips**. Both tagged frozen apps passed, as did the required workspace and security gates. [Verification and hashes](U91-RELEASE-VERIFICATION.md).

No new live-model truth benchmark is claimed. Built-in philosophical overviews
are application text; broader model discussion still depends on following the
policy. Optional encryption from U90 remains off by default, with its existing
[coverage and recovery limits](ENCRYPTION-MIGRATION-PLAN.md).

The release uses the existing independently held owner key. Owner manifests
are separate from Windows-trusted Authenticode and Apple notarization; operating
system publisher warnings remain. [Signing and recovery](OWNER-RELEASE-SIGNING.md).
Physical encrypted USB memory persistence and clean-machine installation remain
manual checks. No existing user data is migrated by this release.
