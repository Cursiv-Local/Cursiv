## Install or update

Use `Cursiv-Setup-3.14-U86.exe` or its identical `Cursiv-Setup-latest.exe` alias
and `SHA256SUMS.txt`. Apple Silicon Mac uses the versioned DMG or stable
`Cursiv-mac-latest.dmg` and `SHA256SUMS-mac.txt`. U86 is higher than U85, so
the normal updater can offer it when online checks are allowed. Offline mode
blocks GitHub requests. No automatic installation on the owner's PC occurs.
