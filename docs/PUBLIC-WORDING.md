# Public wording (October 2026)

One description of Cursiv, used the same way everywhere, so search engines and people see one consistent
thing. Lead with field research; offline AI is a feature, not the headline. Say "tamper-evident", never
"tamper-proof". Don't claim reviews, partners or users that don't exist.

## One line (GitHub About, X bio, LinkedIn headline)
Offline field research software: a tamper-evident field notebook, field calculations checked against
published methods, and an optional local AI assistant. Free and open source.

## Short paragraph (LinkedIn About, directory listings)
Cursiv is free, open-source field research software for Windows. It records observations in a
tamper-evident field notebook, works out field calculations (conductivity, discharge, oxygen saturation,
dilutions) with code checked against published methods, runs from a USB drive, and works offline after
setup. An optional local AI assistant helps with writing and looking things up, but records and numbers
never depend on it. Built by an independent developer; results are the project's own testing.
https://cursiv.us
