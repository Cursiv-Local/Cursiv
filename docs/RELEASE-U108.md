# Cursiv v3.14-U108 — core reliability and automatic source inspection

U108 improves how everyday requests reach Cursiv's existing tools and how Cursiv
explains its own implementation. [Validation and limitations](U108-VALIDATION.md)
contains the measurements and retained failures. Publication is tracked in
[the handoff](U108-HANDOFF.md); this document alone does not establish release status.

- Read-only restrictions preserve permitted file reads. Source investigations use
  the authorized workspace, report real paths/lines and stay separate from notebook actions.
- Notebook lookup recognizes sample IDs and record IDs. Explicit confirmation requests
  return an editable preview before saving; procedural instructions stay out of observations.
- Natural implementation questions and current-chat follow-ups automatically receive
  versioned, fingerprint-checked public source. Normalized control sections retain branches
  and order. Own-source explanations and optional reviews stay local.
- Critical confirmation, correction-history and fallback-order explanations are app-owned,
  conditional on inspected source witnesses. A changed witness stops the explanation;
  a model cannot certify the rule. These reads do not inspect private notebook records.
- Available-history recall quotes actual supplied messages. Incompatible-unit requests
  receive native refusals. Explicit brief banter excludes unrelated private/operational context.

Before version preparation the isolated Windows suite passed **2,508 tests, 15 skips
and 19 subtests**. Original native regressions improved **3/19 to19/19**. Four newly
frozen critical-rule questions returned correct native explanations without model calls.
These small synthetic evaluations are Codex review, not independent human accuracy studies.

General model explanations can still misinterpret code, and humor remains inconsistent.
Shorter replies and valid references do not establish complete codebase understanding.
No self-editing agent, additional tool authority, private-workspace indexing or online
source fallback was added. Field Station code, user data and unrelated profiles are unchanged.

Installer/signature, native platform and public-download checks must be read from the
completed release verification record, not inferred from source tests. Owner release
signatures are distinct from Windows Authenticode and Apple notarization.
