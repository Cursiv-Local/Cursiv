Open-source offline AI

AI without a connection.

Cursiv is free, open-source software. After setup, supported local tools run on your computer.

Works offline

  • Local chat with an installed Ollama model.
  • Saved conversations and memory.
  • Notebook entries, photos, corrections and exports.
  • Imported document retrieval and supported calculations.

Needs internet

Initial downloads, web search, updates and optional cloud AI need a connection. The website’s Phone AI Companion also uses a server; it is separate from the browser-local phone notebook.

Type offline on to block Cursiv’s outside connections. This controls Cursiv, not other software on the computer.

Open source, plainly

Cursiv’s application code uses the MIT license. Ollama and each model have separate licenses. A local setup can still produce wrong answers.
