Field Station · preview

A notebook server for the field.

An experimental local-server preview for phones, tablets and laptops.

What you are seeing

Not yet tested on a physical Raspberry Pi. These screens run on Windows with simulated hardware readings. Pi Wi-Fi setup, a one-step installer and real-device validation remain planned.

Built so far

  • Browser notebook with recording, corrections, search and exports.
  • Sign-in and an encrypted notebook that locks after restart.
  • Health readings labelled real, derived, simulated, stale or unavailable.

Before relying on it

The local preview uses HTTP. It is not end-to-end HTTPS protection. Battery runtime and local-model performance have not been established on a Pi.

No hardware kit is for sale, and no battery is recommended as validated. Read the status and plan.
