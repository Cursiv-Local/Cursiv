Local AI documentation and notebook evidence.

Cursiv is a free, open-source local AI assistant with tamper-evident notebooks. These public documents explain what the application does, how it is checked and where its guarantees stop.

Record history and verify changes

The notebook appends observations, links corrections to their originals, verifies its SHA-256 record chain and supports signed exports. Verify against a trusted fingerprint or known signing key; a self-consistent rewritten chain alone is not proof of original history or observation accuracy.

Retrieve local documents and records

Research Files imports supported documents and supplies relevant text for local questions, with page references where available. Current native notebook retrieval preserves supported date, site, sample and measurement filters. Retrieved text can be incomplete, and the model can misinterpret it.

Research workspace behavior and limits · Dated notebook retrieval tests · Research Files and navigation tests

Understand offline and private operation

Local chat uses an installed runtime and model. Offline mode blocks Cursiv’s outside connections while keeping supported local tools available. Optional cloud providers, web search, updates and downloads need a connection and have different data flows.

Reproducible offline checks · Desktop privacy details · Threat model

Portable does not mean traceless

A prepared Windows kit can include Cursiv, Ollama, models and chosen data. Managed data travels on the drive; host hardware, Windows and drivers are still required. Portable data is readable by design, and the host can retain system traces.

What travels and what stays · Physical persistence checklist · Recovery procedures

Separate tests from promises

Software tests check specific behavior in their recorded environments. Model benchmarks describe particular prompts, models and scoring rules. Neither is a universal accuracy or safety score, an independent review, or a study of first-time users.

U106 source, package and signature evidence · Published measurements and failures · Platforms and untested hardware · Model names and license notes

Read the current boundaries before adopting it

Windows is the primary desktop platform; the Apple Silicon Mac build is early and there is no Linux installer. Project labels do not isolate the shared imported library. General report comparisons, broader conversational exports, comprehensive dated aggregates and human usability studies remain unfinished. The experimental Field Station has not been validated on a physical Raspberry Pi.

For everyday use, read the installation guide, hardware guide and local AI comparison. The MIT application license is separate from the licenses of your runtime and model.
