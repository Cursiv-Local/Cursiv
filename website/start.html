Download and setup

Install Cursiv.

About ten minutes, most of it downloading. You need internet once, for the downloads. After that, everyday use works without it.

Download Cursiv-Setup.exe Mac (early): Cursiv.dmg Release notes

Mac (early): Apple Silicon (M1 or newer), macOS 12+. Drag Cursiv into Applications. It isn't signed by Apple yet, so the first time: try to open it, then System Settings → Privacy & Security → Open Anyway. Built and tested automatically on Apple hardware, but not yet used by anyone on their own Mac. The USB drive is Windows-only.

Current release: U94. A Cursiv USB that starts reliably, with Check drive and Update USB that never overwrite newer data. Test evidence and installer checks · GitHub Releases · MIT license

U94 has an owner-signed release manifest, verified by Cursiv’s pinned public key. This is separate from Windows certificate trust: the installer still has no Windows-trusted publisher signature. Cursiv is seeking open-source code-signing support from the SignPath Foundation.

Verify the download and owner identity

Compare the installer’s SHA-256 with the value below. A checksum detects changed bytes; the signed manifest authenticates those bytes to clients that already trust the owner key. A checksum on the same compromised download page alone does not prove who published it.

Steps

From download to first answer.

  1. Check the download (optional)Every release lists the installer's SHA-256 checksum in SHA256SUMS.txt on its release page. In PowerShell, Get-FileHash .\Cursiv-Setup-3.14-U94.exe -Algorithm SHA256 must print the same value. The installer is built from the public source code at the release's tag.
  2. Run the installerOpen Cursiv-Setup-3.14-U94.exe. It installs into your own user folder (no administrator rights), adds a Start menu entry, and nothing else: no services, drivers or browser changes. It has no Windows-trusted publisher signature, so Windows may say "Windows protected your PC": verify the owner manifest and checksum before deciding to run it. The first page of the installer says the same.
  3. Create your loginPick a username and password, and answer the security questions; they're how you reset a forgotten password. Both stay on this computer. Cursiv doesn't open without this login.
  4. Let Setup install the local AIThe Setup window installs Ollama, the free engine that runs AI models on your computer, then downloads the model you pick (it suggests one for your graphics card). Progress bars show how far along it is.
  5. Start askingType a question. Type help to see what Cursiv can do, and offline on if you want nothing to leave this computer.

Optional online extras

Off unless you turn them on.

You can add your own AI keys in ⚙ Settings: free Google Gemini or Groq keys, or paid OpenAI, Claude or xAI keys. Keys are encrypted for your Windows account.

  • When the local model can't answer (or for images), your message goes to the provider of a key you added.
  • Cursiv Cloud, a free backup on this website, is off by default.
  • Web search runs only for messages starting with search:.
  • Updates: tray icon → Check for Updates, or turn on automatic checks in Settings.

Free keys: Google Gemini · Groq

Help

Common questions.

Where is my data kept?

In a .cursiv folder in your Windows user folder and in Cursiv's program folder: ordinary files. ⚙ Settings has an "Open folder" button. Saved AI keys are encrypted; conversations and memories aren't encrypted on disk.

How do I update?

Right-click the Cursiv icon in the Windows tray (by the clock) and choose Check for Updates. If a newer version exists, Cursiv downloads its installer from GitHub and runs it. Your data is kept.

Can I run it from a USB drive?

Yes: tray icon → Make a Cursiv USB… copies Cursiv, Ollama and your models to a 64 GB+ exFAT drive. Leave "Include my memories, keys and settings" unticked for a copy you give to someone else.

How do I uninstall?

Windows Settings → Apps → Cursiv → Uninstall. Ollama and its models are separate; uninstall Ollama the same way to remove them.

Something went wrong.

Use tray icon → Send problem report… (it shows you what will be sent before sending), or open an issue on GitHub.
