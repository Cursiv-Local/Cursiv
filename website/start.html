Download & setup

Install Cursiv.

Download the app, then let Setup install Ollama and a local model. Initial downloads need internet.

Download for WindowsMac · early build

Current release: U116. A cleaner chat bar, safer memory commands and fewer false science warnings. Test evidence and installer checks · MIT license

From download to first answer.

  1. InstallOpen Cursiv-Setup-3.14-U116.exe. Windows may show an unknown-publisher warning; review the signing details below before deciding to run it.
  2. Create your local loginChoose your login and encryption passphrase. Keep your recovery information safe.
  3. Let Setup prepare local AIInstall Ollama and the suggested model, qwen3:4b-instruct (about 2.5 GB).
  4. Ask a questionType help for tools or offline on to block Cursiv’s outside connections.

Before you install

  • Windows: 10/11, 64-bit. Start with 8 GB RAM; 16 GB recommended. Allow about 4–8 GB for runtime and one model.
  • Mac: Apple Silicon, macOS 12+. Early build; not Apple-signed or notarized. Automated tests do not replace first-hand Mac use.
  • Portable drives: Windows only. Read the short guide.

Help when you need it

Where is my data?

Covered conversations, memories and notebook records are encrypted on a computer. Portable data and explicit exports have different limits. Read the storage policy.

How do I update or uninstall?

Update from the Cursiv tray icon → Check for Updates. Uninstall through Windows Settings → Apps. Ollama and its models are separate.

Can I use online AI?

Optional providers and web search need internet and send the content needed for the request. Keep offline mode on when you want outside connections blocked.
