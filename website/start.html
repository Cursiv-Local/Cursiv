Download and setup

Install Cursiv on Windows.

About ten minutes, most of it downloading. You need internet once, for the downloads. After that, everyday use works without it.

Download Cursiv-Setup.exe Release notes

Latest release: v3.14-U65 · about 80 MB · from GitHub · MIT license

SystemWindows 10 or 11, 64-bit
Memory8 GB RAM (16 GB recommended)
DiskAbout 4–8 GB free for Ollama and one model; more for extra models
GraphicsOptional. A 4 GB+ NVIDIA or AMD card makes answers much faster.
Steps

From download to first answer.

  1. Run the installerOpen Cursiv-Setup-latest.exe. The installer isn't code-signed yet, so Windows may say "Windows protected your PC": click More info, then Run anyway.
  2. Create your loginPick a username and password, and answer the security questions; they're how you reset a forgotten password. Both stay on this computer. Cursiv doesn't open without this login.
  3. Let Setup install the local AIThe Setup window installs Ollama, the free engine that runs AI models on your computer, then downloads the model you pick (it suggests one for your graphics card). Progress bars show how far along it is.
  4. Start askingType a question. Type help to see what Cursiv can do, and offline on if you want nothing to leave this computer.
Which model

Setup suggests the model that tested best.

ModelDownloadWhen
qwen3 4B Instruct (Apache 2.0)2.5 GBRecommended for every computer. It did best on Cursiv's side-by-side tests: 40 of 40, about 10 seconds an answer on a 4 GB graphics card. Without a graphics card it's slower (not yet measured).
qwen2.5 1.5B (Apache 2.0)1 GBOnly for computers too slow for qwen3 4B. Not yet tested by Cursiv's benchmark.

Optional extras in Setup: a coding model and an image-reading model. Each model has its own license; see MODELS.md.

Optional online extras

Off unless you turn them on.

You can add your own AI keys in ⚙ Settings: free Google Gemini or Groq keys, or paid OpenAI, Claude or xAI keys. Keys are encrypted for your Windows account.

  • When the local model can't answer (or for images), your message goes to the provider of a key you added.
  • Cursiv Cloud, a free backup on this website, is off by default.
  • Web search runs only for messages starting with search:.
  • Updates: tray icon → Check for Updates, or turn on automatic checks in Settings.

Free keys: Google Gemini · Groq

Help

Common questions.

Where is my data kept?

In a .cursiv folder in your Windows user folder and in Cursiv's program folder: ordinary files. ⚙ Settings has an "Open folder" button. Saved AI keys are encrypted; conversations and memories aren't encrypted on disk.

How do I update?

Right-click the Cursiv icon in the Windows tray (by the clock) and choose Check for Updates. If a newer version exists, Cursiv downloads its installer from GitHub and runs it. Your data is kept.

Can I run it from a USB drive?

Yes: tray icon → Make a Cursiv USB… copies Cursiv, Ollama and your models to a 64 GB+ exFAT drive. Leave "Include my memories, keys and settings" unticked for a copy you give to someone else.

How do I uninstall?

Windows Settings → Apps → Cursiv → Uninstall. Ollama and its models are separate; uninstall Ollama the same way to remove them.

Something went wrong.

Use tray icon → Send problem report… (it shows you what will be sent before sending), or open an issue on GitHub.
