A few useful answers.

Is it free?

Yes. Cursiv uses the MIT license. Ollama and each model have separate licenses. Windows is the main platform; the Mac build is early.

What works offline?

Local chat, notebook records, imported documents and supported tools after setup. Web search, cloud AI and the Phone AI Companion need internet.

Where does my work stay?

Local work stays on your computer. Covered app data is encrypted on a computer; portable data is readable by design. Storage and online-feature details.

Why does Windows show an unknown publisher?

Windows publisher signing is pending. Releases have a separate owner-signed manifest. Check the download and signing status.
