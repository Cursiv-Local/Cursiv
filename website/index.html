Public development history

Built through continuous development.

Cursiv’s publicly documented history dates back to at least May 2026. The May 17, 2026 version 3 release described multi-model AI orchestration, persistent memory and a local workspace. That early environment coordinated cloud providers, with Ollama available for offline use.

Since then, Cursiv has evolved toward free, open-source local AI with tamper-evident notebooks, offline document retrieval, calculations checked in code and portable research workspaces. Its focus is researchers and independent workers who need detailed records and useful tools without relying on a cloud connection.

Before you download

A few practical details.

What do I need to run it?

Windows 10 or 11, 64-bit, with 8 GB RAM as a starting point; 16 GB is recommended. Allow space for Cursiv, Ollama and your model. A graphics card helps, but speed depends on the model and hardware. Setup can install Ollama and download a model. See the hardware guide and installation steps.

What works without internet?

After setup, local chat, memory, saved conversations and supported local tools work with their required files installed. Offline mode blocks outside connections and stays on after a restart. Web search, cloud AI, the website phone companion, downloads and update checks need a connection. Optional online features send the content needed for their requests. Read the offline guide.

Does local storage mean encryption?

On a computer, yes: since U97 conversations, memories, the field notebook and its photos are encrypted on disk with your passphrase, and there's no way in without it. A Cursiv USB drive stays readable by design, so it works on any computer; use full-drive encryption if you carry sensitive records. Saved API keys use Windows account protection. If you use an online provider or the website phone companion, those services have separate data paths. The Privacy Policy explains what is stored, what can leave the computer and the website's download analytics.

How are answers checked?

Ollama generates a local answer. Cursiv can supply relevant reference material, saved information and results from supported calculations, then check selected claims. These checks are limited and can miss mistakes. Some reference entries still lack published sources, and none has medical-professional review. The testing guide explains the evidence; technical documentation covers the architecture.

Is it free? Which platforms are supported?

Cursiv's source code is free under the MIT license. Models have their own licenses; review the terms of the model you choose. Windows is the main platform. An early Apple Silicon Mac build is on the download page; Linux is not yet supported. Portable USB/SSD operation is Windows-only, and broader field validation is still needed.

Why does Windows show an unknown publisher?

Windows publisher signing is pending; Release manifests are owner-signed with a separate pinned key. Cursiv is seeking open-source signing support from the SignPath Foundation. Review the source, release notes and published SHA-256 checksum before deciding to install. The download guide explains signing status and setup. Public source code and a matching checksum identify a build; they do not guarantee it is free of defects.
