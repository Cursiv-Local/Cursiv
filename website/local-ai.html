Local AI for your documents and notes.

Free, open-source local AI for Windows. Chat, search imported documents and keep a notebook that preserves corrections.

One place for your work

  • Ask your documents. Find relevant passages with page references.
  • Keep useful context. Save conversations and selected memories.
  • Preserve the original. Record observations, measurements and linked corrections.
  • Check supported calculations. Let code handle the arithmetic.

Start local. Stay in control.

Cursiv uses Ollama and a separately licensed model. Download both during setup; supported local work then runs without internet. Cloud providers and web search are optional.

Windows is the main platform. The Apple Silicon Mac build is early; there is no Linux installer. See hardware guidance.

AI can still be wrong. Imported documents are shared across workspaces; labels are not access boundaries.
