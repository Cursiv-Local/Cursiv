# Cursiv

Read `HANDOFF.md` before changing chat, memory, phases, or verification.

Start any "where is X?" search with `docs/CODE-MAP.md`: every module, one line each, grouped by job, with the message flow at the top. `tests/test_code_map.py` keeps it complete, so add a line there when you add a module.

The verification overhaul (a real check after `chat()` has a draft, an assumption ledger on complex turns, memory origin tags with safety precedence, `tests/test_verify.py`) is committed and released since v3.14-U59. `HANDOFF.md` has the details, what not to change, and what each release since added.
